# Option A1 - Expert Q&A Follow-Up

Use `A1` when expert-to-expert questions were collected in a prior discussion round and need explicit resolution.

## Best For

- resolving expert questions raised during `A`,
- clarifying assumptions before the swarm pivots elsewhere,
- preventing useful disagreement from collapsing into ambiguity,
- converting expert interaction debt into concrete route updates.

## Output Shape

- Moderator reasoning
- clearly listed question-and-answer pairs
- compact route / todo update
- next option selection

## Quality Bar

- each collected question is answered explicitly,
- answers are substantive rather than one-line acknowledgements,
- unresolved questions are either answered or kept visible as active debt,
- the round produces sharper route state, not just polite clarification.

## Failure Modes

- skipping `A1` after collecting expert questions,
- answering only some questions and silently dropping the rest,
- treating `A1` as filler instead of a real clarifying round,
- using `A1` when no real expert questions exist.
