# Option D - Structured Adjudication

Use `D` when there is a real fork and competing routes need a practical decision.

## Best For

- forcing a route choice,
- surfacing hidden assumptions behind competing paths,
- testing whether one route is actually stronger or only more exciting,
- comparing tradeoffs under the same evidence boundary.

## Output Shape

- Moderator reasoning
- explicit competing routes
- strongest case for each route
- one challenge pass
- adjudication / winning route
- route update
- next option selection

## Quality Bar

- the competing routes are genuinely distinct,
- the tradeoffs are explicit,
- each route answers the strongest challenge against it,
- the round sharpens route choice rather than staging a performance,
- the outcome changes what the process does next.

## Lightweight Structure

Prefer a lean staged structure:
1. define the competing routes,
2. let each route state its strongest case,
3. run one challenge pass against both routes,
4. adjudicate and update route status.

Use `X` instead of `D` when the task needs a true adversarial contest, burden-of-proof pressure, or cross-examination of incompatible positions.

## Failure Modes

- comparing artificial routes,
- drifting into a generic pros/cons summary,
- turning adjudication into theatrical debate,
- letting multiple routes survive without explicit reason,
- choosing a winner without a real challenge pass.
